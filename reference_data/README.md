# Справочные данные

В этой папке хранятся исходные справочники для наполнения системы.

Примеры файлов:

- `universities.xlsx`
- `regions.csv`
- `it_directions.csv`
- `vendors.xlsx`

Правила:

- один справочник — один файл;
- первая строка содержит названия колонок;
- для CSV используется кодировка UTF-8;
- персональные данные, пароли и другие секреты сюда не добавляются;
- историю изменений файлов хранит Git, поэтому даты и версии в имени файла не нужны.

Автоматический импорт этих файлов пока не выполняется.
